# แฟ้มผลงาน – ธนากร กดมงคล

เว็บไซต์แฟ้มผลงานประกอบการประเมินผลการปฏิบัติงาน พนักงานราชการ
รอบการประเมิน **1 เมษายน 2569 – 30 กันยายน 2569**

## โครงสร้างไฟล์

```
index.html
assets/
  css/style.css      ← สไตล์ทั้งหมด
  js/data.js         ← ข้อมูลเนื้อหาเว็บไซต์ (หัวข้อ ข้อความ ลิงก์รูป)
  js/app.js          ← โค้ดการทำงานของเว็บไซต์ (เมนู, การ์ด, ตัวดูสไลด์, กล่องขยายภาพ)
  img/
    evidence/        ← ภาพหลักฐานประกอบแต่ละหัวข้อ (64 ไฟล์)
    slides/          ← ภาพสไลด์ต้นฉบับทั้ง 46 หน้า
    thumbs/          ← ภาพย่อของสไลด์ ใช้ในแถบเลือกหน้า
    portrait.webp    ← ภาพโปรไฟล์
```

ไม่มีการพึ่งพาไฟล์หรือลิงก์จากภายนอกใดๆ ยกเว้นฟอนต์ **Anuphan** ที่โหลดจาก Google Fonts เท่านั้น (ถ้าต้องการใช้แบบออฟไลน์ทั้งหมด ให้ดาวน์โหลดไฟล์ฟอนต์มาไว้ในโปรเจกต์แล้วแก้ลิงก์ในแท็ก `<link>` ที่ `index.html`)

เปิดไฟล์ `index.html` โดยดับเบิลคลิกจากเครื่องได้เลย ทำงานได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์

## วิธีอัปโหลดขึ้น GitHub

1. สร้าง repository ใหม่บน GitHub (เลือก Public)
2. ลากทั้ง**โฟลเดอร์นี้ทั้งหมด** (ไฟล์และโฟลเดอร์ย่อยทุกไฟล์) เข้าไปในหน้า **Add file → Upload files** แล้วกด Commit
   - ถ้าใช้ `git` จากเครื่อง: `git add . && git commit -m "เพิ่มเว็บไซต์แฟ้มผลงาน" && git push`
3. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch** → Branch **main** → โฟลเดอร์ **/(root)** → Save
4. รอ 1–2 นาที แล้วเข้าลิงก์ `https://<username>.github.io/<repo-name>/`

## แก้ไขเนื้อหาภายหลัง

เนื้อหาข้อความทั้งหมดอยู่ใน `assets/js/data.js` เปิดด้วยโปรแกรมแก้ไขข้อความทั่วไปแล้วแก้ไขข้อความในตัวแปร `window.SITE_DATA` ได้โดยตรง โครงสร้างเป็น JSON ปกติ
